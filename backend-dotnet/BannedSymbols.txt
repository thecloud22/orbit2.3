# Determinism guard. Temporal workflow code is replayed, so it must never read the clock, generate random
# values, sleep or schedule work on its own. Workflows use Workflow.UtcNow / Workflow.NewGuid / Workflow.Random /
# Workflow.DelayAsync / Workflow.WhenAnyAsync instead. Activities and the rest of the app may do I/O, but the same
# rules are applied to the whole assembly so a call cannot slip into a workflow by accident: use the injected
# TimeProvider for time, and put a `#pragma warning disable RS0030` with a reason where a real exception is needed.
